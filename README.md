# iPet

Sistema de gestão para clínicas veterinárias, da Daco Digital.

Esta é a **versão de demonstração**: roda inteira no navegador, com dados
fictícios gerados no próprio aparelho. Não há servidor, não há banco e
nenhum dado de cliente real passa por aqui.

- PIN da demonstração: `1234`
- Dá para trocar de perfil (dono, veterinária, recepção, banho e tosa,
  auxiliar, financeiro) pelo menu do nome, no topo da barra lateral.

Tudo que for digitado some ao recarregar a página.
